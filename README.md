# phii

> creative space for expression and expression

A minimalist, Wabi-Sabi inspired web experience exploring negative space (*Ma*), asymmetry (*Fukinsei*), and austere simplicity (*Kanso*).

## Tech Stack

- **React 19**
- **Vite**
- **Tailwind CSS v4**

## Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
